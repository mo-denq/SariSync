# SariSync

**A Shared Digital Price Book for Family Sari-Sari Stores**

## Overview

SariSync is a web-based application designed to help family members look up and maintain consistent product prices in a family sari-sari store. It aims to reduce reliance on memory and outdated price lists when multiple family members take turns assisting customers.

## Problem Statement

Family members helping run a sari-sari store may struggle to remember updated product prices, especially when grocery costs change. This can lead to inconsistent pricing and possible underpricing. SariSync provides a shared digital price book to make product price lookup easier and help family members keep prices updated.

## Key Features

- **Product Search** – Search for products and check their current listed prices.
- **Barcode Scanning** – Scan product barcodes to help find products.
- **Category Browsing** – Browse products by category.
- **Price Updates** – Update product prices when needed.
- **Responsive Interface** – Use the web app on supported screen sizes.
- **Installable Web App** – Supports installation on compatible devices.
