# Page-specific styles

This folder is reserved for a future screen that genuinely needs styles not
shared by the rest of SariSync.

For now, uncertain and page-specific rules remain in `../components.css`.
Keeping them together preserves their existing cascade order and prevents an
accidental visual redesign during the Phase 5 architecture refactor.
