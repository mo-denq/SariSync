# SariSync source files

This folder contains the files that make the browser application look and work.

- `css` contains the visual design.
- `js` contains page behavior, navigation, data helpers, and services.
- `assets` is reserved for local images, logos, and other media.

The root `index.html` remains outside this folder so VS Code Live Server can
continue opening the prototype normally.
